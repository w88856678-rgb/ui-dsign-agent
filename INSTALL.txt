UI DSign Agent · Codex 安装说明

在线安装

在 Codex 中发送下面一行。

$skill-installer 请从 https://github.com/w88856678-rgb/ui-dsign-agent/tree/main/skills/ui-dsign-agent 安装 UI DSign Agent 到我的个人技能目录。

从 ZIP 安装

解压 ui-dsign-agent.zip，把整个 ui-dsign-agent 文件夹复制到个人 Codex 技能目录。

  macOS / Linux    ~/.codex/skills/
  Windows          %USERPROFILE%\.codex\skills\

目录还没有时可以先建好。如果自定义了 CODEX_HOME，请使用其下的 skills 目录。复制后，文件位置应为 skills/ui-dsign-agent/SKILL.md。
