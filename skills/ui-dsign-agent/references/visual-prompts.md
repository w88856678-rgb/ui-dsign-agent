# UI 和视觉素材提示词

## 多屏界面

按需求使用这些字段。参考图反推时先提取图中能观察到的特征，再补产品需求。

1. **载体**。目标设备、画幅、单屏或多屏、稿件类型。
2. **产品**。名称、目标用户、主要任务、需要覆盖的页面。
3. **共用视觉规则**。主辅色及角色、字级、网格、留白、圆角、图标与插画。
4. **共用组件**。导航、卡片、表单、按钮、反馈组件及状态。
5. **逐屏模块**。从上到下写内容、关键文案、状态与主操作。示例，顶部为日期及筛选，中部为今日记录，底部保留添加入口。
6. **构图与呈现**。视口、界面占比、屏幕排列、所需场景或素材。
7. **约束**。保留的现有结构和品牌规则，以及需要避免的重复、遮挡、内容截断或布局拥挤。

## 视觉素材

通用顺序是成品用途和画幅 → 主体、动作和叙事 → 构图与布景 → 风格、配色、材质与光线 → 需要保留或排除的可见特征。按下面的差异补充。用于改图时，给每张参考图分配一个清楚的用途。

| 类型 | 应明确的字段 |
|---|---|
| 3D 图标、徽章和运营小组件 | 轮廓和识别特征。批量统一机位、主体占比、倒角、光向、背景。按部件写材质，区分表面贴图、浮雕和独立立体部件。 |
| 活动主视觉、海报、启动页和弹窗 | 画幅、主角在做什么、前中后景的层次。指定可覆盖标题和 CTA 的区域，说明道具的优先级。 |
| IP 与周边 | 草图固定轮廓、五官、比例和标志性元素。参考图可以提供单独的姿势、材质或产品形态，例如保留角色动作，只改转 3D 后的材质。 |
| 艺术标题字 | 引号内放准确文案，指定单行或换行、对比、笔画、连笔和收笔。用于成品时逐字核对错漏，需要可编辑文字时保留可编辑文本。 |
| B 端和直播素材 | 先定义界面里素材放在哪、占多少、要不要给数据或文字留位置。蓝白磨砂玻璃、霓虹和赛博朋克都是可选风格。 |
| 循环微动 | 写清哪些部件做什么、各自动作幅度和节奏、镜头和表情是否锁定。分段动作写时间点。预期无缝循环时检查首尾衔接和主体形变。 |

风格词可以拆成可见特征。例如把「软胶潮玩」写成圆润轮廓、低反光哑面、柔和高光和棚拍软阴影，把「新中式」落实到配色、纸张肌理、构图和道具。快速迭代时每轮优先修改一个显著变量，比较两版差异。
